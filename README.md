# FYP Management System

A multi-role desktop application for managing Final Year 
Project workflows between students, lecturers and admins.

## Tech Stack
- C#, WinForms, SQL Server

## Features
- Role-based access — Admin, Lecturer, Student
- Secure authentication with encryption (BouncyCastle)
- Proposal submission and supervisor assignment
- Grading management and progress tracking
- Resource management and system audit logs
- Session management and access control

## Setup
1. Open VP_PBE.slnx in Visual Studio
2. Restore NuGet packages automatically
3. Update connection string in DatabaseConnection.cs
4. Build and run
